✨ Features
📋 Multiple Application Types
Create different application types (Staff, Support, Design…).
🛡️ Smart Requirements
Set which roles are allowed to review applications, plus a blacklist system for unwanted users.
✅ Accept & Reject
Reviewers accept or reject applications — applicants get an automatic DM notification with the result.
🎭 Automated Role Management
On acceptance, the bot automatically grants the configured roles.
